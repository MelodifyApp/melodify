## Findings so far (2026-11-21)

A basic public web search found GitHub, YouTube and Instagram handles using
“Quelody”, but **no live music/streaming app** with that name. `quelody.app`,
`.com`, `.dev` and `.io` did not resolve. This is **not** a clearance opinion.

Previous name “Melodify” was already used by several music apps; the rename to
Quelody reduces that specific conflict.

## Decision for 1.1.0

The app is free, local-only and directly distributed. It is not listed in a
store and is not monetized. The owner accepts the residual name risk for this
release; the formal searches above are still required before a wider launch.

## Before any public launch or monetization

1. Complete the searches above and save screenshots/results.
2. Acquire or park a domain before publishing a download page.
3. If there is a conflict, rename before publishing; do not rely on a
   “different enough” argument.
4. Get a one-hour Turkish IT/KVKK/trademark consult if anything is ambiguous.
5. Keep platform names in plain text and do not use Spotify/Kick/Twitch logos.
